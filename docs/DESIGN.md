# 视觉与交互

暖白背景`#FAF8F5`、正文`#302D29`、次要文字`#716B63`、陶土色`#A9593E`。三页共用560逻辑像素窗口，随设备数调整高度，超出工作区时滚动；不加多级折叠或常驻说明文字。

- 手动启动直接展示主窗口，再次双击恢复已有窗口；登录自启保持后台托盘。启动失败用原生错误弹窗显示原因及处理建议，不新增常驻说明文字。
- 主页面顶部是概览栏：左侧标题“外设电量”，中间一行居中的灰字摘要“N 台设备 · 最低 X% · 更新时间”，下方一条 1 设备像素分隔线；摘要只从当前显示的行推导，列表变化时同步变化。没有设备时摘要显示“暂无设备”。读取时间只在这里出现一次，行内不再重复。
- 主页面设备行：类型图标、简短型号，右侧同一行依次为十格满量程电池、实际百分比、并排两个设备开关（左托盘、右提醒）。开关含义只在标题栏右侧标一次：11px 小字“托盘”“提醒”，分别对齐两列开关，不逐行重复、也不额外占一行高度。设备行内容在自己的行带内垂直居中。下一行是“连接方式 · 已使用时长 · 满电续航”，占满整行宽度。充电中用“充电中”替换使用时长。75%画七格半，87%画八格加七成，不把数值取整。已确认断开的设备不占用行；没有已连接设备时显示一行说明。手动刷新仍只在托盘菜单。
- 窗口造型：无标题栏、无边框的弹出面板（对齐 Win10 时钟/日历面板）：整块自绘、1px 细边线、系统投影；不出现标题栏按钮，所以头部即拖动区，关闭靠 Esc / 托盘图标再点一次 / Alt+F4。
- 窗口站位：默认**右下角**（工作区右缘 + 任务栏上方），高度随行数变化时底边不动、向上生长，所以换页或设备增减都不会把页脚推进任务栏。设置页「窗口固定」开启（默认）时位置固定不可拖动；关闭后可拖头部，锚点记“左边 + 底边”。
- 配色双态，跟随系统“应用模式”（不是本应用自己的开关）：浅色 `#F5F8FA` 底 / `#292D30` 字 / `#636B71` 次要 / `#3E59A9` 强调；深色 `#1F1F1F` 底 / `#F2F2F2` 字 / `#A0A0A0` 次要 / `#0078D4` 强调 / 分隔 `#3A3A3A`。高对比度优先走系统色，两条自定义配色都不参与。
- 主页头部：左列头固定文字“外设名称”（20px 粗体，24–228），不是标题也不随设备变化；中右概览（12px 次要色，右对齐到 360，左界 120）：`N 台设备 · 最低 x% · 更新时间`；“历史使用”入口 366–450，字号与“托盘/提醒”同为 11px（18–42 同一条行带）；列头“托盘”456–494 / “提醒”498–536。
- 历史页（只读）：标题“历史使用”+ 返回箭头；**只列当前已连接的设备，每台两行**（行高与其他页一致 64）。第一行：型号（17px 粗体，64–296，8–34）+ 右侧“最长 X · 最短 Y”（15px 次要色，右对齐 300–536，同一条行带）；第二行：`当前 MM-DD HH:MM → 现在 · x% → y% · 已用…`（12px 次要色，64–536，36–56）。仅一条记录时只写“最长 X”；没有完整记录写“尚无完整满电记录”；起始电量未记录按 100%。不显示“进行中”主数值，也不给历史段的日期/电量区间。空态一行“暂无已连接的设备”。
- 设置：只有偏好项，不列设备，双列等宽（24–272 / 288–536），控件各自对齐到本列右缘。顺序固定：开机自启｜连接提示；低电提醒｜提醒阈值；自动刷新｜刷新间隔；刷新间隔下方一行 12px 说明（整行宽，内容固定为“调长间隔可延长外设续航；支持电量通知的外设会优先用通知更新。”）；最后一排同样是双列：左「所有设备的托盘与提醒」，右「窗口固定」（默认开）。设置页高度 304（说明行占 22px、总开关下移 20px）。即时持久化。总开关一次改写所有设备的托盘与提醒；任一设备关闭时显示“全部关闭”，点击即全部打开。阈值与间隔数字按实际字体高度在外框中垂直居中，与右侧单位对齐，留白也可点击编辑。鼠标操作隐藏焦点框，键盘导航显示；保留Tab/Shift+Tab、Enter/Space与原生语义。
- 添加：展示已连接设备；支持设备可添加/显示已添加，所有行均可复制信息，已监控的行尾额外提供“移除”（整行宽度依次为 复制信息、添加/已添加、移除）。导出与复制内容重复，入口已删除。按钮沿用现有次要文字样式；采集中禁用重复操作，完成显示已复制/已导出。未适配行不显示无意义的添加按钮，不在UI线程扫描，不增加说明小字。
- 满电续航：从观察到 100% 且未在充电时开始计时，到该设备首次降到提醒阈值（含）为止记一条记录；充电会放弃未完成的计时，不补记。主页面第二行末尾显示最近一次（“满电续航5小时12分”），悬停显示最近三次。每条设备只保留最近 8 条，随设置文件 v10 持久化，跨重启继续计时。
- 主窗口与托盘共用填色设备造型；托盘左设备、右有边框的连续尺。无分格、无轮播、无空闲动画。悬停显示型号与百分比。
- 软件图标为纵向单列电池格，蓝牙和2.4G位于右侧上下同规格底牌；小尺寸独立处理。
- 手柄保留十字键及四个菱形排列按钮。16类及通用兜底是视觉覆盖，不是硬件支持证明。高对比使用系统颜色。

## 自绘控件与图标规范

- 自绘形状（开关、按钮、输入框、电池、分隔线）先光栅化到设备像素的预乘 ARGB 面，再 `AlphaBlend` 落屏；不用 GDI 的 `RoundRect`/`Ellipse`/`Rectangle`/`Polygon` 直接绘制，它们在非 96 DPI 下没有抗锯齿，圆角接近短边一半时还会被压成折角。
- 开关为 38×22 逻辑像素胶囊，滑块为直径 16 的正圆，左右内边距各 3；开态轨道用陶土色、关态用描边色，滑块用纸面色（高对比取系统高亮文字色）。
- 按钮、输入框、焦点环统一 6 逻辑像素圆角；普通描边 1 逻辑像素且贴内沿，焦点环 2 逻辑像素，分隔线 1 设备像素。电池本体 4 逻辑像素圆角，与交互控件区分层级。
- 设备图标统一 28×28 逻辑像素，左边距 24，行内顶部偏移 12，与型号/连接两行文字块垂直居中。已批准栅格尺寸按 1:1 直接使用；其他尺寸缩小走面积平均、放大走双线性，禁止最近邻抽样。
- 配色以 `assets/palette.json` 为准：窗口用 `ui`，托盘用 `tray_light`/`tray_dark`，软件图标用 `software`。深色/浅色只切换托盘配色，窗口始终是暖纸面。

造型源：`tools/device_shapes.py`、`tools/tray_art.py`；软件母版：`assets/source/software/`。运行 `tools/generate_assets.py` 后核对真实尺寸和原生窗口。`assets/source/tray-reference/` 是固定回归栅格，生成器与原生测试均比较；修改设计时明确更新依据。
